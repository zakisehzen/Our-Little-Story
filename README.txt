OUR LITTLE STORY
=================

Website scrapbook hubungan kalian.

Isi:
- index.html
- style.css
- script.js
- photos/

Cara menjalankan:
1. Buka index.html di browser.
2. Untuk musik, tambahkan file bernama "music.mp3" ke folder utama.

Cara membuatnya online:
- Upload seluruh isi folder ini ke GitHub Pages, Netlify, atau Vercel.
- Pastikan struktur folder dan nama file tetap sama.

Catatan:
Semua teks bisa diedit langsung di index.html.
Foto berada di folder photos/.
